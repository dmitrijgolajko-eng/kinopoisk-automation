## Автоматизация тестирования Кинопоиска (UI + API)


Проект содержит набор автоматизированных тестов для веб‑версии Кинопоиска. Используется связка: ****Python 3.13+****, ****Selenium****, ****PyTest****, ****Allure Report****.

### Цель проекта

Обеспечение стабильного и быстрого регрессионного тестирования функционала сайта с минимизацией ручного вмешательства и времени прогона за счёт оптимизации авторизации.

### Задачи проекта

#### Проверка пользовательского интерфейса

-   Валидация основных элементов (хедер, поиск, профиль, баннеры).
-   Проверка адаптивности и корректного отображения контента.

#### Навигация

-   Проверка переходов между страницами (Главная → Поиск → Фильм → Профиль).
-   Валидация URL‑адресов и состояний страниц.

#### Авторизация и управление сессией

-   Оптимизация времени выполнения через использование файлов cookie (полученных через API).
-   Проверка сценариев выхода из аккаунта и истечения сессии.

#### Отчёты

-   Генерация подробных отчётов Allure с разбивкой по шагам.
-   Прикрепление скриншотов при падении тестов.

### Требования к окружению

-   ****Python****: версия 3.13.x.
-   ****Браузер****: Google Chrome (последняя стабильная версия).
-   ****Драйвер****: `chromedriver` устанавливается автоматически.
-   ****Переменные окружения****: файл `.env` с данными авторизации.

### Запуск тестов

#### Подготовка окружения

1.  Создание виртуального окружения:

bash

python -m venv venv  

2.  Активация окружения (Windows):

bash

.\\venv\\Scripts\\Activate.ps1  

3.  Установка зависимостей:

bash

pip install -r requirements.txt  
pip install -r requirements-dev.txt  

#### Режимы запуска

| Режим           | Команда                 | Описание                  |
| --------------- | ----------------------- | ------------------------- |
| UI‑тесты        | pytest -m ui            | Запуск только UI‑тестов.  |
| API‑тесты       | pytest -m api           | Запуск только API‑тестов. |
| Все тесты       | pytest                  | Запуск всех тестов.       |
| Конкретный файл | pytest tests/test_ui.py | Запуск тестов из файла.   |

### Генерация отчётов

bash

allure generate ./allure-results -o ./allure-report --clean  
allure open ./allure-report

-   Файл `.env` не должен коммититься.
-   Код должен соответствовать PEP 8.
-   Все зависимости должны быть в `requirements.txt`.

### Важные комментарии

-   Для работы API тестов вам понадобится ключ от [официального API Кинопоиска](https://kinopoisk.dev/).
-   Куки авторизации сохраняются в файл `cookies.json` и повторно используются, чтобы не выполнять авторизацию на каждый тест (сокращает время выполнения).
-   Все тесты соответствуют PEP 8, используют аннотации типов и детализированные отчеты Allure с скриншотами при падении.
-   Избежаны жесткие `time.sleep()` — используется явное ожидание через `WebDriverWait`.
