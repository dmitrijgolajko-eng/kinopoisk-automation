# Автоматизация тестирования Кинопоиск (UI + API)

Проект содержит набор автоматизированных тестов для веб-версии Кинопоиск. 
Используется связка: **Python + Selenium + PyTest + Allure**.

## Задача проекта

1.  **Проверка UI:** Валидация основных элементов (хедер, поиск, профиль, баннеры).
2.  **Навигация:** Проверка переходов между страницами (Главная -> Поиск -> Фильм).
3.  **Авторизация:** Оптимизация времени прогона за счет использования Cookies (полученных через API) вместо ручного ввода логина/пароля в каждом тесте.
4.  **Отчеты:** Генерация детальных отчетов Allure с разбивкой по шагам (`@allure.step`).

## Структура проекта

| Папка/Файл | Описание |
| :--- | :--- |
| `pages/` | Page Objects (классы страниц). Каждый класс инкапсулирует локаторы и действия. |
| `tests/` | Тестовые сценарии. Разделены на UI и API тесты. |
| `config.py` | Глобальные константы (URL, ID фильмов). |
| `kinopoisk_api.py` | Клиент для взаимодействия с API Кинопоиск (получение токенов). |
| `conftest.py` | Фикстуры Pytest (инициализация драйвера, внедрение куки авторизации). |
| `requirements.txt` | Зависимости для продакшн окружения. |
| `requirements-dev.txt` | Зависимости для разработки (allure, linters). |
